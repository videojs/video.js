# react-native

video.js for react-native

## Installation


```sh
npm install react-native
```


## Usage


```tsx
import { Player } from "@videojs/react-native";

// ...

<Player source="https://stream.mux.com/{PLAYBACK_ID}.m3u8" style={{ width: 320, height: 180 }} />
```
