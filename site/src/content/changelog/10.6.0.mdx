Video.js 10.6.0 expands live playback and makes common streaming, casting, and installation paths more reliable.

## Play live audio and choose live tracks

SPF audio engines now play live CMAF and MPEG-TS streams, with the same live state and controls as video playback ([#9779](https://github.com/videojs/video.js/pull/9779)). Live video presets now include quality and audio-track selection, so viewers can choose a rendition or language on multi-track HLS streams ([#9798](https://github.com/videojs/video.js/pull/9798)).

SPF now reports a failed manifest as a playback error ([#9776](https://github.com/videojs/video.js/pull/9776)), loads enough MPEG-TS media for `preload="metadata"` to reach `loadedmetadata` before playback ([#9778](https://github.com/videojs/video.js/pull/9778)), and preserves media at segment boundaries when seeking. MPEG-TS playback also now stays on the playlist timeline and reaches the end of short final segments ([#9774](https://github.com/videojs/video.js/pull/9774)). The Mux media references now explain when to choose SPF or hls.js: see [Mux Video](/docs/framework/html/reference/components/mux-video/) and [Mux Audio](/docs/framework/html/reference/components/mux-audio/) ([#9787](https://github.com/videojs/video.js/pull/9787)). SPF documentation also corrects details about Mux MPEG-TS packaging and live TS coverage ([#9777](https://github.com/videojs/video.js/pull/9777)).

## Play HyperFrames compositions

`@videojs/hyperframes-video` adds HyperFrames compositions as player media. Use a HyperFrames file or author the composition inline with a `<template>` in HTML or JSX in React; player controls, the time slider, and hotkeys drive it like other media ([#9719](https://github.com/videojs/video.js/pull/9719)).

## Keep casting in sync

Google Cast now detects separate HLS audio segment formats, keeps sidecar text tracks and caption selections in sync with the receiver, and unloads receiver media when you clear the local source ([#9788](https://github.com/videojs/video.js/pull/9788), [#9789](https://github.com/videojs/video.js/pull/9789), [#9726](https://github.com/videojs/video.js/pull/9726)). It also cleans up text-track listeners when a player unmounts ([#9807](https://github.com/videojs/video.js/pull/9807)). A Google Cast refactor also recognizes CRLF-terminated playlists when it detects their segment format ([#9791](https://github.com/videojs/video.js/pull/9791)).

The Default Media Receiver cannot play DRM-protected content, so the Cast button now stays disabled for a protected source until you configure a custom receiver. The [casting guide](/docs/guides/casting/#cast-drm-protected-content) explains how to pass DRM configuration to one ([#9794](https://github.com/videojs/video.js/pull/9794)).

## Installation and player fixes

HTML-only installs no longer pull in React, and documented nested HTML and React import paths now resolve in tools that do not support multi-segment export wildcards ([#9819](https://github.com/videojs/video.js/pull/9819), [#9804](https://github.com/videojs/video.js/pull/9804)). Iframe embeds now fill video skins and retain their aspect ratio outside a skin ([#9821](https://github.com/videojs/video.js/pull/9821)).

Fatal hls.js errors during media attachment now reach the player error state ([#9729](https://github.com/videojs/video.js/pull/9729)). Dash.js releases its media element correctly when a player unmounts ([#9814](https://github.com/videojs/video.js/pull/9814)), and popovers position correctly inside transformed ancestors ([#9762](https://github.com/videojs/video.js/pull/9762)). The site also shortens legacy redirect chains and restores redirects for documented paths that previously reached 404 pages ([#9647](https://github.com/videojs/video.js/pull/9647)).
