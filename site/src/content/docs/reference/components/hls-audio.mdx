Audio-only HLS component that plays only the audio rendition of an HLS stream, even from a mixed audio and video manifest, so no video data is downloaded. It runs on the same engine as the <DocsLink slug="reference/components/hls-video">HLS video component</DocsLink> and takes the same `source`, so one object serves both. For Mux-hosted audio, use the <DocsLink slug="reference/components/mux-audio">Mux audio component</DocsLink>.
