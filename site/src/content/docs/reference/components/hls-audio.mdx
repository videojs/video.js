Audio-only HLS element that plays just the audio rendition of an HLS stream — even when the source is a mixed audio/video manifest. Useful for audio podcast players, background audio, and bandwidth-constrained contexts where downloading video data would be wasted. For full audio/video HLS playback, see the <DocsLink slug="reference/components/hls-video">HLS video component</DocsLink>.

## Import

<MediaImports media="hls-audio" react="HlsAudio" />

## Load a source

`src` takes an HLS manifest URL. A mixed audio/video manifest works too: the audio component loads only the audio rendition.

<FrameworkCase frameworks={["react"]}>
```tsx
<HlsAudio src="https://example.com/playlist.m3u8" />
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```html
<hls-audio src="https://example.com/playlist.m3u8"></hls-audio>
```
</FrameworkCase>

The structured `source` object takes the same shape as the <DocsLink slug="reference/components/hls-video">HLS video component</DocsLink>'s, so one object can serve either. Use `source.type` for a manifest URL without an `.m3u8` extension. `source.drm` is accepted but unused, because this component composes no EME.

<FrameworkCase frameworks={["react"]}>
```tsx
<HlsAudio source={{ src: 'https://example.com/manifest', type: 'application/vnd.apple.mpegurl' }} />
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```ts
const audio = document.querySelector('hls-audio');
audio.source = { src: 'https://example.com/manifest', type: 'application/vnd.apple.mpegurl' };
```
</FrameworkCase>
