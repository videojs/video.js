The default skin of the live video preset: the video layout with the time slider and time displays swapped for a Live button. <DocsLink slug="reference/components/live-video-neutral-skin">NeutralLiveVideoSkin</DocsLink> is the same preset's other variant. See <DocsLink slug="guides/skins">Skins</DocsLink> for how packaged skins work and <DocsLink slug="guides/presets">Presets</DocsLink> for what the live video preset ships.

## Import

<SkinImports preset="live-video" react="LiveVideoSkin" />

## Anatomy

The skin goes between the player and the media component. It renders its controls around the media.

<FrameworkCase frameworks={["react"]}>
```tsx
<LiveVideoPlayer>
  <LiveVideoSkin>
    <HlsVideo />
  </LiveVideoSkin>
</LiveVideoPlayer>
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```html
<live-video-player>
  <live-video-skin>
    <hls-video></hls-video>
  </live-video-skin>
</live-video-player>
```
</FrameworkCase>

This uses the lightweight <DocsLink slug="reference/components/hls-video">HLS video element</DocsLink> because most browsers can't play HLS streams with a plain `<video>`. See <DocsLink slug="guides/live-streams">Play live streams</DocsLink>.

## Poster

<FrameworkCase frameworks={["react"]}>
The skin renders a poster image before playback starts. Pass `renderPoster` to replace it with your own component.
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
The skin renders a poster image before playback starts. An element with `slot="poster"` replaces it.
</FrameworkCase>

See <DocsLink slug="guides/poster">Add a poster and loading placeholder</DocsLink> for complete examples.

## Styling

Packaged skins style themselves and expose a small set of public CSS custom properties. Everything else inside the skin is private and may change between releases. <DocsLink slug="guides/customize-skins" anchor="style-a-packaged-skin">Customize skins</DocsLink> documents the properties. For deeper changes, the Video.js registry provides the skin files.
