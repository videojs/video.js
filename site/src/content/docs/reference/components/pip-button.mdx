## Behavior

Toggles picture-in-picture (PiP) mode. The button derives two state hooks from `availability`:

<FrameworkCase frameworks={["html"]}>
- **`disabled`** (`true` until PiP is available, or when the `disabled` prop is set) — sets `aria-disabled="true"` and `data-disabled`. A prop-disabled, available button stays focusable but does not activate.
- **`hidden`** (`true` while PiP is `"unavailable"` or `"unsupported"`) — applies the native HTML `hidden` attribute on the custom element.
</FrameworkCase>

<FrameworkCase frameworks={["react"]}>
- **`disabled`** (`true` until PiP is available, or when the `disabled` prop is set) — sets `aria-disabled="true"` and `data-disabled`. A prop-disabled, available button stays focusable but does not activate.
- **`hidden`** (`true` while PiP is `"unavailable"` or `"unsupported"`) — the component returns `null`.
</FrameworkCase>

## Styling

You can style the button based on PiP state:

<FrameworkCase frameworks={["html"]}>
```css
/* In PiP mode */
media-pip-button[data-pip] {
  background: red;
}

/* Non-interactive (disabled prop) */
media-pip-button[data-disabled] {
  opacity: 0.5;
  cursor: not-allowed;
}
```
</FrameworkCase>

<FrameworkCase frameworks={["react"]}>
React renders a `<button>` element. Add a `className` to style it:

```css
/* In PiP mode */
.pip-button[data-pip] {
  background: red;
}

/* Non-interactive (disabled prop) */
.pip-button[data-disabled] {
  opacity: 0.5;
  cursor: not-allowed;
}
```
</FrameworkCase>

The button remains hidden until picture-in-picture is available.

<FrameworkCase frameworks={["html"]}>
The element receives the native `hidden` attribute. No extra CSS is required.
</FrameworkCase>

<FrameworkCase frameworks={["react"]}>
The component returns `null`. No extra CSS is required.
</FrameworkCase>

## Accessibility

The default English `aria-label` is "Enter picture-in-picture", or "Exit picture-in-picture" while picture-in-picture is active. The `label` prop overrides it. The button supports keyboard activation with <kbd>Enter</kbd> or <kbd>Space</kbd>.
