A media component plays the content inside a player. Each one plays a format or a provider through one engine.

## Files the browser plays

<FrameworkCase frameworks={["react"]}>
| Component | Plays | Engine |
|---|---|---|
| <DocsLink slug="reference/components/video">Video</DocsLink> | Any file the browser plays, such as MP4 and WebM, and HLS in browsers with built-in HLS | The browser |
| <DocsLink slug="reference/components/audio">Audio</DocsLink> | Any audio file the browser plays, such as MP3 and AAC | The browser |
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
| Component | Plays | Engine |
|---|---|---|
| <DocsLink slug="reference/components/video">`<video>`</DocsLink> | Any file the browser plays, such as MP4 and WebM, and HLS in browsers with built-in HLS | The browser |
| <DocsLink slug="reference/components/audio">`<audio>`</DocsLink> | Any audio file the browser plays, such as MP3 and AAC | The browser |
</FrameworkCase>
