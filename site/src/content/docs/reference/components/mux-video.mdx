Video component for Mux-hosted streams. From a playback ID it derives the stream, poster, and timeline thumbnail URLs, and it plays signed and DRM-protected assets from their tokens. It plays through SPF, Video.js's own engine, or through hls.js, depending on the import path. The <DocsLink slug="reference/components/mux-audio">Mux audio component</DocsLink> plays audio-only assets.

### Cast DRM-protected content

Google's Default Media Receiver can't license DRM, so while the source has a `drm.token`, the Cast button stays disabled until the Google Cast extension's `receiver` is set. <DocsLink slug="guides/casting" anchor="cast-drm-protected-content">Cast DRM-protected content</DocsLink> covers hosting your own receiver and passing it a license server through `customData`.

Build the Widevine license URL from the playback ID and DRM token: `https://license.mux.com/license/widevine/{playbackId}?token={drmToken}`. A receiver built with [Mux's Google Cast DRM guide](https://www.mux.com/docs/guides/play-drm-protected-videos-on-google-cast) reads `customData.mux` instead. For that receiver, pass `{ mux: { playbackId, tokens: { drm: drmToken } } }`, the format Mux Player sends.

  source={{
    playbackId: 'BV3YZtogl89mg9VcNBhhnHm02Y34zI1nlMuMQfAbl3dM',
    customDomain: 'media.example.com',
    playback: { maxResolution: '1080p' },
  }}
  playsInline
  crossOrigin="anonymous"

</FrameworkCase>
