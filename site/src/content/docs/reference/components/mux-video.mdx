Video component for Mux-hosted streams. Give it a playback ID and it builds the stream, poster, and storyboard URLs, and it plays signed and DRM-protected assets from their tokens. It plays through hls.js, like the <DocsLink slug="reference/components/hlsjs-video">hls.js video component</DocsLink>, and takes the same engine options. For audio-only assets, use the <DocsLink slug="reference/components/mux-audio">Mux audio component</DocsLink>. Start with <DocsLink slug="guides/mux">Play Mux videos</DocsLink>.

### With a playback ID

<FrameworkCase frameworks={["react"]}>
```tsx
<MuxVideo
  source={{
    playbackId: 'BV3YZtogl89mg9VcNBhhnHm02Y34zI1nlMuMQfAbl3dM',
    customDomain: 'media.example.com',
    playback: { maxResolution: '1080p' },
  }}
  playsInline
  crossOrigin="anonymous"
/>
```
</FrameworkCase>
