Video component for Mux-hosted streams. Give it a playback ID and it builds the stream, poster, and storyboard URLs, and it plays signed and DRM-protected assets from their tokens. It plays through SPF, Video.js's own engine, or through hls.js like the <DocsLink slug="reference/components/hlsjs-video">hls.js video component</DocsLink>, depending on which entry point you import. For audio-only assets, use the <DocsLink slug="reference/components/mux-audio">Mux audio component</DocsLink>. Start with <DocsLink slug="guides/mux">Play Mux videos</DocsLink> for playback IDs, signed playback, and DRM, then add <DocsLink slug="guides/mux-data">Mux Data</DocsLink> to monitor playback and <DocsLink slug="guides/casting">casting</DocsLink> to play on a TV.

## Import

<MediaImports media="mux-video" package="@videojs/mux-video" react="MuxVideo" />

The Mux video component plays through one of two engines, chosen by import path: SPF, Video.js's own engine, or hls.js. The default import uses hls.js today and will switch to SPF in an upcoming release.

| Import | Engine |
|---|---|
| `.../media/mux-video/spf` | SPF |
| `.../media/mux-video` | hls.js today, SPF in an upcoming release |
| `.../media/mux-video/hls-js` | hls.js |

<FrameworkCase frameworks={["react"]}>
```tsx
import { MuxVideo } from '@videojs/react/media/mux-video/spf';
```

All three imports give you a `MuxVideo` component with the same basic API.
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```ts
import '@videojs/html/media/mux-video/spf';
```

All three imports register the same `<mux-video>` tag with the same basic API. Load only one of them on a page: the first one to load claims the tag, and the others are ignored.
</FrameworkCase>

<DocsLink slug="guides/mux" anchor="choose-a-playback-engine">Play Mux videos</DocsLink> covers when to use each engine.

### With a playback ID

<FrameworkCase frameworks={["react"]}>
```tsx
<MuxVideo
  source={{
    playbackId: 'BV3YZtogl89mg9VcNBhhnHm02Y34zI1nlMuMQfAbl3dM',
    customDomain: 'media.example.com',
    playback: { maxResolution: '1080p' },
  }}
  playsInline
  crossOrigin="anonymous"
/>
```
</FrameworkCase>
