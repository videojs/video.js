Audio component for Mux-hosted streams. Give it a playback ID and it builds the stream URL, and it plays signed assets from their tokens. It plays through hls.js, like the <DocsLink slug="reference/components/hlsjs-video">hls.js video component</DocsLink>, and takes the same engine options. For video, use the <DocsLink slug="reference/components/mux-video">Mux video component</DocsLink>. Start with <DocsLink slug="guides/mux">Play Mux videos</DocsLink>.
