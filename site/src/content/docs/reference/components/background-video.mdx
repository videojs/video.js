Decorative background video for a source the browser can play natively. By default it's muted, looped, and autoplaying.

<FrameworkCase frameworks={["react"]}>
`BackgroundVideo` renders a native `<video>`. Override the defaults with native React props such as `muted={false}`, `loop={false}`, or `autoPlay={false}`, and size the video with `className` or `style`. Its `ref` and `mediaRef` both resolve to that `HTMLVideoElement`.
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
`<background-video>` renders a `<video>` inside shadow DOM and fills the box you give the component. Use the opt-out attributes in the [API](#api) to change its playback defaults.
</FrameworkCase>

An HLS URL only works where the browser has native HLS playback. See <DocsLink slug="guides/background-video">Add a background video</DocsLink> to choose a cross-browser HLS or Mux path and set up layout, poster, and decorative semantics.

## API

<FrameworkCase frameworks={["html"]}>
### Attributes

| Attribute | Description |
| --- | --- |
| `src` | URL of a video the browser can play directly, such as an MP4 or WebM file |
| `nomuted` | Turns off muting |
| `noloop` | Turns off looping |
| `noautoplay` | Turns off autoplay |
| `crossorigin`, `preload`, `controls`, `controlslist` | Passed through to the inner video |

An explicit `muted`, `loop`, or `autoplay` attribute wins over its opt-out. Opt-outs and passed-through attributes also apply when set or changed after the element is created.

### Properties

| Property | Description |
| --- | --- |
| `src` | URL of the video. Assigning a new one restarts playback |
| `error` | The inner video's `MediaError`, or `null` |
| `target` | Inner native `<video>` element. Call `play()` and `pause()` on it |

The element also fires an `error` event when the inner video does.
</FrameworkCase>

<FrameworkCase frameworks={["react"]}>
`BackgroundVideo` accepts native `<video>` props. Its `ref` and `mediaRef` both resolve to the rendered `HTMLVideoElement`.
</FrameworkCase>

## Styling

<FrameworkCase frameworks={["html"]}>
| Custom property | Default | Description |
| --- | --- | --- |
| `--media-object-fit` | `inherit` | How the video fits its box |
| `--media-object-position` | `50% 50%` | Position of the video within its box |

Set an explicit size on the custom element or an author-owned wrapper.
</FrameworkCase>

<FrameworkCase frameworks={["react"]}>
`BackgroundVideo` is the native `<video>` element. Set its size, `object-fit`, and `object-position` through `className` or `style`.
</FrameworkCase>
