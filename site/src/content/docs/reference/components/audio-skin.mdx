The default skin of the audio preset: the control layout for on-demand audio with the modern, frosted look. <DocsLink slug="reference/components/audio-neutral-skin">NeutralAudioSkin</DocsLink> is the same preset's other variant. See <DocsLink slug="guides/skins">Skins</DocsLink> for how packaged skins work and <DocsLink slug="guides/presets">Presets</DocsLink> for what the audio preset ships.

## Import

<SkinImports preset="audio" react="AudioSkin" />

## Anatomy

The skin goes between the player and the media component. It renders its controls around the media.

<FrameworkCase frameworks={["react"]}>
```tsx
<AudioPlayer>
  <AudioSkin>
    <Audio />
  </AudioSkin>
</AudioPlayer>
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```html
<audio-player>
  <audio-skin>
    <audio></audio>
  </audio-skin>
</audio-player>
```
</FrameworkCase>

## Styling

Packaged skins style themselves and expose a small set of public CSS custom properties. Everything else inside the skin is private and may change between releases. <DocsLink slug="guides/customize-skins" anchor="style-a-packaged-skin">Customize skins</DocsLink> documents the properties. For deeper changes, the Video.js registry provides the skin files.
