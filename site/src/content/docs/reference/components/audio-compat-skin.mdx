The Compat skin of the audio preset: the same core controls with plain, unbranded surfaces that avoid newer visual effects such as backdrop blur. Its time slider supports chapter segments and thumbnail previews, and it adds captions and AirPlay buttons that the default audio skin leaves out. The preset also provides <DocsLink slug="reference/components/audio-skin">AudioSkin</DocsLink>, <DocsLink slug="reference/components/audio-neutral-skin">NeutralAudioSkin</DocsLink>, and <DocsLink slug="reference/components/audio-scaffold-skin">ScaffoldAudioSkin</DocsLink>. See <DocsLink slug="guides/skins" anchor="choose-a-skin">Skins</DocsLink> to choose between them and <DocsLink slug="guides/customize-skins">Customize skins</DocsLink> to install and edit its source.

<SkinImports preset="audio" react="CompatAudioSkin" compat />

## Anatomy

The skin goes between the player and the media component. It renders its controls around the media.

<FrameworkCase frameworks={["react"]}>
```tsx
<AudioPlayer>
  <CompatAudioSkin>
    <Audio />
  </CompatAudioSkin>
</AudioPlayer>
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```html
<audio-player>
  <audio-compat-skin>
    <audio></audio>
  </audio-compat-skin>
</audio-player>
```
</FrameworkCase>

## Styling

Packaged skins style themselves and expose a small set of public CSS custom properties. Everything else inside the skin is private and may change between releases. <DocsLink slug="guides/customize-skins" anchor="style-a-packaged-skin">Customize skins</DocsLink> documents the properties. For deeper changes, the Video.js registry provides the skin files.
