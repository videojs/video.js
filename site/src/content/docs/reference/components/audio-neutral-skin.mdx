The neutral skin of the audio preset: the same player and the same controls in a visually lighter design, closer to a classic control bar. <DocsLink slug="reference/components/audio-skin">AudioSkin</DocsLink> is the same preset's other variant. See <DocsLink slug="guides/skins">Skins</DocsLink> for how packaged skins work and <DocsLink slug="guides/presets">Presets</DocsLink> for what the audio preset ships.

## Import

<SkinImports preset="audio" react="NeutralAudioSkin" neutral />

## Usage

The skin goes between the player and the media element. It renders its controls around the media.

<FrameworkCase frameworks={["react"]}>
```tsx
<AudioPlayer>
  <NeutralAudioSkin>
    <Audio src="audio.mp3" />
  </NeutralAudioSkin>
</AudioPlayer>
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```html
<audio-player>
  <audio-neutral-skin>
    <audio src="audio.mp3"></audio>
  </audio-neutral-skin>
</audio-player>
```
</FrameworkCase>

## Styling

Packaged skins style themselves and expose a small set of public CSS custom properties. Everything else inside the skin is private and may change between releases. <DocsLink slug="guides/customize-skins" anchor="style-a-packaged-skin">Customize skins</DocsLink> documents the properties. For deeper changes, the Video.js registry provides the skin files.
