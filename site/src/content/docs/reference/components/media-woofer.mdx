Adds the media woofer <DocsLink slug="guides/architecture">extension</DocsLink> to the player. It renders nothing — place it anywhere inside the player, and it follows whatever media the player attaches. While the media plays, the media element shakes on every hit of bass, and phones that support the [Vibration API](https://developer.mozilla.org/en-US/docs/Web/API/Vibration_API) vibrate with it.

## Options

## Audio access

The extension reads the media's sound with the [Web Audio API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API), which reroutes the element's audio through an audio graph for as long as the element exists. To keep playback audible, it only does so when the browser lets audio run and the sound is readable:

- It starts on the first play after a user gesture. Until the browser allows audio, the media plays untouched.
- Cross-origin media needs the `crossorigin` attribute and CORS headers. Without them the browser hides the sound from Web Audio, so the extension leaves that media alone.

Once an element's audio is routed through the graph, it stays routed. A cross-origin source loaded into the same element later without CORS plays silently.

The shake is skipped when the user prefers reduced motion; vibration still applies.
