The audio counterpart of <DocsLink slug="reference/components/lazy-video">LazyVideo</DocsLink>: reads `src`, renders the media component that plays it, and loads that component's code only once the source is known.

## Import

<FrameworkCase frameworks={["react"]}>
```bash
npm install @videojs/react @videojs/mux-audio @videojs/spotify-audio @videojs/soundcloud-audio @videojs/mixcloud-audio
```

```tsx
import { LazyAudio } from '@videojs/react/media/lazy-audio';
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```bash
npm install @videojs/html @videojs/mux-audio @videojs/spotify-audio @videojs/soundcloud-audio @videojs/mixcloud-audio
```

```ts
import '@videojs/html/media/lazy-audio';
```
</FrameworkCase>

## Sources

| Source | Resolves to | Loads |
|---|---|---|
| Audio and video files | Native `<audio>` | Nothing |
| HLS on Safari, or where there's no MSE | Native `<audio>` | Nothing |
| HLS, elsewhere | <DocsLink slug="reference/components/hls-audio">HlsAudio</DocsLink> | The SPF HLS engine |
| `stream.mux.com` | <DocsLink slug="reference/components/mux-audio">MuxAudio</DocsLink> | Mux Audio |
| Spotify | <DocsLink slug="reference/components/spotify-audio">SpotifyAudio</DocsLink> | The Spotify embed |
| SoundCloud | <DocsLink slug="reference/components/soundcloud-audio">SoundCloudAudio</DocsLink> | The SoundCloud widget |
| Mixcloud | <DocsLink slug="reference/components/mixcloud-audio">MixcloudAudio</DocsLink> | The Mixcloud widget |

A source that matches none of these, including YouTube, Vimeo, and DASH, renders nothing and logs an error in development.

## Custom media

<FrameworkCase frameworks={["react"]}>
`createLazyAudio` builds a `LazyAudio` from a list of media, tried in order, the same way <DocsLink slug="reference/components/lazy-video">`createLazyVideo`</DocsLink> does. The built-in media are `audio`, `hlsAudio`, `muxAudio`, `spotifyAudio`, `soundcloudAudio`, and `mixcloudAudio`, each imported from `@videojs/react/media/lazy/` plus its kebab-case name.

```tsx
import { audio } from '@videojs/react/media/lazy/audio';
import { createLazyAudio } from '@videojs/react/media/lazy/create';
import { muxAudio } from '@videojs/react/media/lazy/mux-audio';

const MuxLazyAudio = createLazyAudio([audio, muxAudio]);
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
`createLazyAudioElement` builds a `<lazy-audio>` class from a list of media, tried in order, the same way <DocsLink slug="reference/components/lazy-video">`createLazyVideoElement`</DocsLink> does. The built-in media are `audio`, `hlsAudio`, `muxAudio`, `spotifyAudio`, `soundcloudAudio`, and `mixcloudAudio`, each imported from `@videojs/html/media/lazy/` plus its kebab-case name.

```ts
import { audio } from '@videojs/html/media/lazy/audio';
import { createLazyAudioElement } from '@videojs/html/media/lazy/create';
import { muxAudio } from '@videojs/html/media/lazy/mux-audio';

customElements.define('mux-lazy-audio', createLazyAudioElement([audio, muxAudio]));
```
</FrameworkCase>

`LazyAudio` takes the same `src`, `type`, `preferPlayback`, and `preload` options as `LazyVideo`, and loads and passes props on the same way. See <DocsLink slug="reference/components/lazy-video">LazyVideo</DocsLink> for its behavior and API reference.
