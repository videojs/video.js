The audio counterpart of <DocsLink slug="reference/components/lazy-video">LazyVideo</DocsLink>: reads `src`, renders the media component that plays it, and loads that component's code only once the source is known.

## Import

<FrameworkCase frameworks={["react"]}>
```tsx
import { LazyAudio } from '@videojs/react/media/lazy-audio';
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```ts
import '@videojs/html/media/lazy-audio';
```
</FrameworkCase>

## Sources

| Source | Resolves to | Loads |
|---|---|---|
| Audio and video files | Native `<audio>` | Nothing |
| HLS on Safari, or where there's no MSE | Native `<audio>` | Nothing |
| HLS, elsewhere | <DocsLink slug="reference/components/hls-audio">HlsAudio</DocsLink> | The SPF HLS engine |
| `stream.mux.com` | <DocsLink slug="reference/components/mux-audio">MuxAudio</DocsLink> | Mux Audio |

A source that matches none of these, including YouTube, Vimeo, and DASH, renders nothing and logs an error in development.

`LazyAudio` takes the same `src`, `type`, `preferPlayback`, and `preload` options as `LazyVideo`, and loads and passes props on the same way. See <DocsLink slug="reference/components/lazy-video">LazyVideo</DocsLink> for its behavior and API reference.
