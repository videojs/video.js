The Compat skin of the live audio preset provides basic controls and plain surfaces, with broader browser compatibility as its design goal. It shows a Live button in place of time controls. See <DocsLink slug="guides/customize-skins">Customize skins</DocsLink> to install and edit its source.

## Import

<SkinImports preset="live-audio" react="CompatLiveAudioSkin" compat />

## Usage

The skin goes between the player and the media element. It renders its controls around the media.

<FrameworkCase frameworks={["react"]}>
```tsx
<LiveAudioPlayer>
  <CompatLiveAudioSkin>
    <MuxAudio src="live.m3u8" />
  </CompatLiveAudioSkin>
</LiveAudioPlayer>
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```html
<live-audio-player>
  <live-audio-compat-skin>
    <mux-audio src="live.m3u8"></mux-audio>
  </live-audio-compat-skin>
</live-audio-player>
```
</FrameworkCase>

The examples use the <DocsLink slug="reference/components/mux-audio">Mux audio element</DocsLink>: a plain `<audio>` can't play HLS in most browsers, and this element reports the live playback state the skin's Live button needs. See <DocsLink slug="guides/live-streams">Play live streams</DocsLink>.

## Styling

Packaged skins style themselves and expose a small set of public CSS custom properties. Everything else inside the skin is private and may change between releases. <DocsLink slug="guides/customize-skins" anchor="style-a-packaged-skin">Customize skins</DocsLink> documents the properties. For deeper changes, the Video.js registry provides the skin files.
