HLS video component that hands playback to the browser's built-in HLS support, as in Safari. It adds no streaming engine, so it's the smallest HLS option, and it only plays where the browser supports HLS. For HLS in every browser, use the <DocsLink slug="reference/components/hlsjs-video">hls.js video component</DocsLink> or the <DocsLink slug="reference/components/hls-video">HLS video component</DocsLink>. It licenses DRM through FairPlay only; see <DocsLink slug="guides/drm">Play DRM-protected content</DocsLink>.

  <Fragment slot="engine-nativeHls">
    This element hands playback to the browser, so there's no JavaScript engine to configure. This carries the one thing native playback still needs from you. <DocsLink slug="guides/media-sources">Media sources</DocsLink> covers how engine options fit into a structured source.

    <FrameworkCase frameworks={["react"]}>
    ```tsx
    <NativeHlsVideo
      source={{
        src: 'https://example.com/playlist.m3u8',
        engine: {
          nativeHls: {
            drmSystems: { 'com.apple.fps': { licenseUrl: 'https://example.com/license' } },
          },
        },
      }}
    />
    ```
    </FrameworkCase>

    <FrameworkCase frameworks={["html"]}>

    const video = document.querySelector('native-hls-video')!;
