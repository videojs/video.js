DASH video element powered by [dash.js](https://github.com/Dash-Industry-Forum/dash.js/) for MPEG-DASH adaptive bitrate streaming.

## Import

<MediaImports media="dash-video" package="@videojs/dash-video" react="DashVideo" />

## Load a source

`src` takes a DASH manifest (MPD) URL.

<FrameworkCase frameworks={["react"]}>
```tsx
<DashVideo src="https://example.com/manifest.mpd" />
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```html
<dash-video src="https://example.com/manifest.mpd"></dash-video>
```
</FrameworkCase>

The structured `source` object pairs the URL with dash.js settings under `engine.dashJs`. Setting `source` derives `src`, and changing `engine.dashJs` applies the settings to the running player instead of recreating it.

<FrameworkCase frameworks={["react"]}>
```tsx
<DashVideo
  source={{
    src: 'https://example.com/manifest.mpd',
    engine: { dashJs: { streaming: { buffer: { bufferTimeAtTopQuality: 30 } } } },
  }}
/>
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```ts
const video = document.querySelector('dash-video')!;
video.source = {
  src: 'https://example.com/manifest.mpd',
  engine: { dashJs: { streaming: { buffer: { bufferTimeAtTopQuality: 30 } } } },
};
```
</FrameworkCase>

<MediaReference media="DashVideo">
  <Fragment slot="engine-dashJs">
    Pass dash.js's own settings here. They're handed to dash.js untouched, so every option in its [settings reference](https://cdn.dashjs.org/latest/jsdoc/module-Settings.html) works. Replacing the object resets any settings applied before it. <DocsLink slug="guides/media-sources">Media Sources</DocsLink> covers how engine options fit into a structured source.

    Each of the three below is a group of dash.js settings rather than a single value, and dash.js documents what's inside them.

    <FrameworkCase frameworks={["react"]}>
    ```tsx
    <DashVideo
      source={{
        src: 'https://example.com/manifest.mpd',
        engine: { dashJs: { streaming: { buffer: { fastSwitchEnabled: true } } } },
      }}
    />
    ```
    </FrameworkCase>

    <FrameworkCase frameworks={["html"]}>
    ```ts
    const video = document.querySelector('dash-video');
    video.source = {
      src: 'https://example.com/manifest.mpd',
      engine: { dashJs: { streaming: { buffer: { fastSwitchEnabled: true } } } },
    };
    ```
    </FrameworkCase>
  </Fragment>
