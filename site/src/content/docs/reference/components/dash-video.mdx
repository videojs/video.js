DASH video component powered by [dash.js](https://github.com/Dash-Industry-Forum/dash.js/) for MPEG-DASH adaptive bitrate streaming. It doesn't read `source.drm`; for DRM-protected DASH, use the <DocsLink slug="reference/components/shaka-video">Shaka video component</DocsLink>. <DocsLink slug="guides/media-sources">Media sources</DocsLink> explains how `source.engine.dashJs` settings apply.

<MediaReference media="DashVideo">
  <Fragment slot="engine-dashJs">
    Pass dash.js's own settings here. They're handed to dash.js untouched, so every option in its [settings reference](https://cdn.dashjs.org/latest/jsdoc/module-Settings.html) works. Replacing the object resets any settings applied before it. <DocsLink slug="guides/media-sources">Media sources</DocsLink> covers how engine options fit into a structured source.

    Each of the three below is a group of dash.js settings rather than a single value, and dash.js documents what's inside them.

    <FrameworkCase frameworks={["react"]}>
    ```tsx
    <DashVideo
      source={{
        src: 'https://example.com/manifest.mpd',
        engine: { dashJs: { streaming: { buffer: { fastSwitchEnabled: true } } } },
      }}
    />
    ```
    </FrameworkCase>

    <FrameworkCase frameworks={["html"]}>
    ```ts
    const video = document.querySelector('dash-video')!;
    video.source = {
      src: 'https://example.com/manifest.mpd',
      engine: { dashJs: { streaming: { buffer: { fastSwitchEnabled: true } } } },
    };
    ```
    </FrameworkCase>
  </Fragment>
</MediaReference>
