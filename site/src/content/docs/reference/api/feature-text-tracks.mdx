Manages subtitles, captions, chapters, and thumbnail tracks.

`textTrackList` lists the media's tracks, then the tracks an app adds to the player with the <DocsLink slug="reference/api/feature-text-cues">text cues feature</DocsLink>'s `addTextTrack()`. Each track's `source` is `'media'` or `'app'`. An app `captions` or `subtitles` track is copied into the media so the browser can draw it, and it's selected and listed like the media's own; its copy isn't listed separately. Media without text tracks of their own, such as embeds, list only app tracks.

A default `kind="chapters"` track can also divide the <DocsLink slug="reference/components/time-slider">time slider</DocsLink> into chapter ranges and label the chapter at the current interaction position. When the media has no chapters track, `chaptersCues` reads the first chapters track the app added instead.

This feature doesn't track cues as they become active. The text cues feature does, for metadata and chapters tracks and for any track a reader asks for.

`thumbnailsTrack` is the first `kind="metadata"` track labeled `thumbnails`, or `null` when there is none. Its `crossOrigin` reports the media component's CORS mode, or `null` when the media is not CORS-enabled. <DocsLink slug="reference/components/thumbnail">Thumbnail</DocsLink> reads it to fetch sprite sheets the same way the browser fetched the track.

### Selector

<FrameworkCase frameworks={["react"]}>
Pass `selectTextTrack` to <DocsLink slug="reference/api/use-player">`usePlayer`</DocsLink> to subscribe to text track state. Returns `undefined` if the text tracks feature is not configured.
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
Pass `selectTextTrack` to <DocsLink slug="reference/api/player-controller">`PlayerController`</DocsLink> to subscribe to text track state. Returns `undefined` if the text tracks feature is not configured.
</FrameworkCase>

<FrameworkCase frameworks={["react"]}>
```tsx title="CaptionsButton.tsx"
import { selectTextTrack, usePlayer } from '@videojs/react';

function CaptionsButton() {
  const tracks = usePlayer(selectTextTrack);
  if (!tracks) return null;

  return (
    <button onClick={() => tracks.toggleSubtitles()}>
      {tracks.subtitlesShowing ? 'Hide captions' : 'Show captions'}
    </button>
  );
}
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```ts title="captions-button.ts"
import { createPlayer, UIElement, selectTextTrack } from '@videojs/html';
import { videoFeatures } from '@videojs/html/video';

const { PlayerController } = createPlayer({ features: videoFeatures });

class CaptionsButton extends UIElement {
  readonly #textTracks = new PlayerController(this, selectTextTrack);
}
```
</FrameworkCase>
