<FrameworkCase frameworks={["react"]}>
`@videojs/react/live-video` is the preset for live video streams. It bundles `LiveVideoPlayer`, the `liveVideoFeatures` bundle it is configured with, two skins that swap the time slider and time displays for a Live button, and the `Video` media component. See <DocsLink slug="guides/presets">Presets</DocsLink> for how presets fit together and <DocsLink slug="guides/live-streams">Live streams</DocsLink> for playing a live source.
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
`@videojs/html/live-video` is the preset for live video streams. It bundles the `<live-video-player>` element, the `liveVideoFeatures` bundle it is configured with, and two skins that swap the time slider and time displays for a Live button, and plays through the browser's native `<video>`. See <DocsLink slug="guides/presets">Presets</DocsLink> for how presets fit together and <DocsLink slug="guides/live-streams">Live streams</DocsLink> for playing a live source.
</FrameworkCase>

## Import

<FrameworkCase frameworks={["react"]}>
```tsx
import { LiveVideoPlayer, LiveVideoSkin, Video } from '@videojs/react/live-video';
import '@videojs/react/live-video/skin.css';
```

Each skin has its own stylesheet. Import `@videojs/react/live-video/neutral-skin.css` instead when you use `NeutralLiveVideoSkin`.
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```ts
import '@videojs/html/live-video/player';
import '@videojs/html/live-video/skin';
```

Import `@videojs/html/live-video/neutral-skin` instead for the neutral skin. Or load one <DocsLink slug="guides/cdn">CDN</DocsLink> bundle that registers the player and a skin together:

```html
<script type="module" src="{{VJS10_CDN_BASE}}/live-video.js"></script>
```

`live-video-neutral.js` registers the neutral skin instead, and `live-video-player.js` registers `<live-video-player>` alone.
</FrameworkCase>

## Usage

Live streams are usually HLS, so this example plays through an HLS media element instead of the preset's native video.

<FrameworkCase frameworks={["react"]}>
```tsx title="App.tsx"
import { HlsJsVideo } from '@videojs/react/media/hlsjs-video';
import { LiveVideoPlayer, LiveVideoSkin } from '@videojs/react/live-video';
import '@videojs/react/live-video/skin.css';

export function App() {
  return (
    <LiveVideoPlayer>
      <LiveVideoSkin>
        <HlsJsVideo src="https://example.com/live.m3u8" />
      </LiveVideoSkin>
    </LiveVideoPlayer>
  );
}
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```html title="index.html"
<script type="module">
  import '@videojs/html/live-video/player';
  import '@videojs/html/live-video/skin';
  import '@videojs/html/media/hlsjs-video';
</script>

<live-video-player>
  <live-video-skin>
    <hlsjs-video src="https://example.com/live.m3u8"></hlsjs-video>
  </live-video-skin>
</live-video-player>
```
</FrameworkCase>

## Player

<FrameworkCase frameworks={["react"]}>
`LiveVideoPlayer` is a <DocsLink slug="reference/components/player">`Player`</DocsLink> created by <DocsLink slug="reference/api/create-player">`createPlayer`</DocsLink> with `liveVideoFeatures`. It provides the player store to its descendants and renders no DOM element of its own.

`LiveVideoPlayerProps` types its props:

| Prop | Type | Description |
| --- | --- | --- |
| `children` | `ReactNode` | Content placed inside the player context: a skin, the media, and your own components. |
| `title` | `string \| null` | The title to display. Takes precedence over the title the media reports; `null` clears your value, so the title falls back to the one the media reports. |
| `poster` | `string \| null` | The poster to display. Takes precedence over the poster the media reports; `null` clears your value, so the poster falls back to the one the media reports. |

`title` and `poster` come from the <DocsLink slug="reference/api/feature-metadata" anchor="player-inputs">metadata feature</DocsLink>.

The preset also exports a `usePlayer` hook typed to `liveVideoFeatures`. Use it from any component inside `LiveVideoPlayer`; see <DocsLink slug="reference/api/use-player">`usePlayer`</DocsLink>.
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
`@videojs/html/live-video/player` registers `<live-video-player>`, whose class is `LiveVideoPlayerElement`. It is a <DocsLink slug="reference/components/player">player</DocsLink> element created by <DocsLink slug="reference/api/html-create-player">`createPlayer`</DocsLink> with `liveVideoFeatures`. It owns the player store but no layout. Put a skin or a <DocsLink slug="reference/components/player-container">`<media-container>`</DocsLink> inside it.

| Attribute | Property | Description |
| --- | --- | --- |
| `content-title` | `contentTitle` | The title to display. Takes precedence over the title the media reports. |
| `poster` | `poster` | The poster to display. Takes precedence over the poster the media reports. |
| `keep-alive` | — | Keeps the player and its store alive when the element leaves the DOM. Call `destroy()` when you're done with it. |

`content-title` and `poster` come from the <DocsLink slug="reference/api/feature-metadata" anchor="player-inputs">metadata feature</DocsLink>. The element's read-only `store` property returns its player store.

The preset root also exports a `PlayerController` bound to the live video player's store. Use it from any custom element inside `<live-video-player>`; see <DocsLink slug="reference/api/player-controller">`PlayerController`</DocsLink>.
</FrameworkCase>

## Feature bundle

`liveVideoFeatures` is the array of <DocsLink slug="guides/features">features</DocsLink> the player is configured with. It is the <DocsLink slug="reference/api/preset-video" anchor="feature-bundle">video preset's</DocsLink> `videoFeatures` without playback rate, quality, and audio-track selection, plus the <DocsLink slug="reference/api/feature-live">live feature</DocsLink>:

<PresetFeatures preset="live-video" />

<FrameworkCase frameworks={["react"]}>
Its type, `LiveVideoFeatures`, is the tuple of those features in order. Import it from the package root:

```tsx
import type { LiveVideoFeatures } from '@videojs/react';
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
Its type, `LiveVideoFeatures`, is the tuple of those features in order. Import it from the package root:

```ts
import type { LiveVideoFeatures } from '@videojs/html';
```
</FrameworkCase>

To add or remove a feature, pass your own array to `createPlayer`. The skins expect the features they render controls for.

<FrameworkCase frameworks={["react"]}>
```tsx
import { createPlayer, streamTypeFeature } from '@videojs/react';
import { liveVideoFeatures } from '@videojs/react/live-video';

const { Player, usePlayer } = createPlayer({
  features: [...liveVideoFeatures, streamTypeFeature],
});
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```ts
import { createPlayer, streamTypeFeature } from '@videojs/html';
import { liveVideoFeatures } from '@videojs/html/live-video';

const { PlayerElement } = createPlayer({
  features: [...liveVideoFeatures, streamTypeFeature],
});

customElements.define('my-live-video-player', PlayerElement);
```
</FrameworkCase>

## Skins

- <DocsLink slug="reference/components/live-video-skin">LiveVideoSkin</DocsLink> — the default skin, which swaps the time controls for a Live button.
- <DocsLink slug="reference/components/live-video-neutral-skin">NeutralLiveVideoSkin</DocsLink> — the visually lighter variant, closer to a classic control bar.

## Media

<FrameworkCase frameworks={["react"]}>
The preset exports <DocsLink slug="reference/components/video">`Video`</DocsLink>, the same component as the video preset, which renders a native `<video>`. Most browsers need a streaming <DocsLink slug="guides/media-sources">media component</DocsLink> to play a live source, such as <DocsLink slug="reference/components/hlsjs-video">`HlsJsVideo`</DocsLink> for HLS.
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
The preset plays through a native <DocsLink slug="reference/components/video">`<video>`</DocsLink>, so it registers no media element of its own. Most browsers need a streaming <DocsLink slug="guides/media-sources">media element</DocsLink> to play a live source, such as <DocsLink slug="reference/components/hlsjs-video">`<hlsjs-video>`</DocsLink> for HLS.
</FrameworkCase>

## Exports

<FrameworkCase frameworks={["react"]}>
`@videojs/react/live-video` exports:

| Export | Description |
| --- | --- |
| `LiveVideoPlayer`, `LiveVideoPlayerProps` | The preconfigured [player](#player). |
| `usePlayer` | The player-store hook, typed to `liveVideoFeatures`. |
| `liveVideoFeatures` | The [feature bundle](#feature-bundle). |
| `LiveVideoSkin`, `LiveVideoSkinProps` | The default [skin](#skins). |
| `NeutralLiveVideoSkin`, `NeutralLiveVideoSkinProps` | The neutral [skin](#skins). |
| `Video`, `VideoProps` | The [media](#media) component. |

Stylesheets: `@videojs/react/live-video/skin.css` and `@videojs/react/live-video/neutral-skin.css`.
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
The preset root, `@videojs/html/live-video`, has no side effects. Importing it never registers an element:

| Export | Description |
| --- | --- |
| `LiveVideoPlayerElement` | The [player](#player) element class. |
| `PlayerController` | The player controller, bound to the live video player's store. |
| `liveVideoFeatures` | The [feature bundle](#feature-bundle). |
| `LiveVideoSkinElement` | The default [skin](#skins) element class. |
| `NeutralLiveVideoSkinElement` | The neutral [skin](#skins) element class. |

Registration entry points are side-effect-only:

| Entry point | Registers |
| --- | --- |
| `@videojs/html/live-video/player` | `<live-video-player>` |
| `@videojs/html/live-video/skin` | `<live-video-skin>`, `<media-container>`, and the UI elements the skin composes |
| `@videojs/html/live-video/neutral-skin` | `<live-video-neutral-skin>`, `<media-container>`, and the UI elements the neutral skin composes |
| `@videojs/html/live-video/ui` | `<media-container>` and the UI elements of the default skin, without the skin, for a layout you write yourself |
| `@videojs/html/live-video/neutral-ui` | `<media-container>` and the UI elements of the neutral skin, without the skin |
</FrameworkCase>
