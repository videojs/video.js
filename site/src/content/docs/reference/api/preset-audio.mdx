<FrameworkCase frameworks={["react"]}>
`@videojs/react/audio` is the preset for on-demand audio. It bundles `AudioPlayer`, the `audioFeatures` bundle it is configured with, two skins, and the `Audio` media component. See <DocsLink slug="guides/presets">Presets</DocsLink> for how presets fit together and how to customize one.
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
`@videojs/html/audio` is the preset for on-demand audio. It bundles the `<audio-player>` element, the `audioFeatures` bundle it is configured with, and two skins, and plays through the browser's native `<audio>`. See <DocsLink slug="guides/presets">Presets</DocsLink> for how presets fit together and how to customize one.
</FrameworkCase>

## Import

<FrameworkCase frameworks={["react"]}>
```tsx
import { Audio, AudioPlayer, AudioSkin } from '@videojs/react/audio';
import '@videojs/react/audio/skin.css';
```

Each skin has its own stylesheet. Import `@videojs/react/audio/neutral-skin.css` instead when you use `NeutralAudioSkin`.
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```ts
import '@videojs/html/audio/player';
import '@videojs/html/audio/skin';
```

Import `@videojs/html/audio/neutral-skin` instead for the neutral skin. Or load one <DocsLink slug="guides/cdn">CDN</DocsLink> bundle that registers the player and a skin together:

```html
<script type="module" src="{{VJS10_CDN_BASE}}/audio.js"></script>
```

`audio-neutral.js` registers the neutral skin instead, and `audio-player.js` registers `<audio-player>` alone.
</FrameworkCase>

## Usage

<FrameworkCase frameworks={["react"]}>
```tsx title="App.tsx"
import { Audio, AudioPlayer, AudioSkin } from '@videojs/react/audio';
import '@videojs/react/audio/skin.css';

export function App() {
  return (
    <AudioPlayer>
      <AudioSkin>
        <Audio src="audio.m4a" />
      </AudioSkin>
    </AudioPlayer>
  );
}
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```html title="index.html"
<script type="module">
  import '@videojs/html/audio/player';
  import '@videojs/html/audio/skin';
</script>

<audio-player>
  <audio-skin>
    <audio src="audio.m4a"></audio>
  </audio-skin>
</audio-player>
```
</FrameworkCase>

## Player

<FrameworkCase frameworks={["react"]}>
`AudioPlayer` is a <DocsLink slug="reference/components/player">`Player`</DocsLink> created by <DocsLink slug="reference/api/create-player">`createPlayer`</DocsLink> with `audioFeatures`. It provides the player store to its descendants and renders no DOM element of its own.

`AudioPlayerProps` types its props:

| Prop | Type | Description |
| --- | --- | --- |
| `children` | `ReactNode` | Content placed inside the player context: a skin, the media, and your own components. |
| `title` | `string \| null` | The title to display. Takes precedence over the title the media reports; `null` clears your value, so the title falls back to the one the media reports. |
| `poster` | `string \| null` | The poster to display. Takes precedence over the poster the media reports; `null` clears your value, so the poster falls back to the one the media reports. |

`title` and `poster` come from the <DocsLink slug="reference/api/feature-metadata" anchor="player-inputs">metadata feature</DocsLink>.

The preset also exports a `usePlayer` hook typed to `audioFeatures`. Use it from any component inside `AudioPlayer`; see <DocsLink slug="reference/api/use-player">`usePlayer`</DocsLink>.
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
`@videojs/html/audio/player` registers `<audio-player>`, whose class is `AudioPlayerElement`. It is a <DocsLink slug="reference/components/player">player</DocsLink> element created by <DocsLink slug="reference/api/html-create-player">`createPlayer`</DocsLink> with `audioFeatures`. It owns the player store but no layout. Put a skin or a <DocsLink slug="reference/components/player-container">`<media-container>`</DocsLink> inside it.

| Attribute | Property | Description |
| --- | --- | --- |
| `content-title` | `contentTitle` | The title to display. Takes precedence over the title the media reports. |
| `poster` | `poster` | The poster to display. Takes precedence over the poster the media reports. |
| `keep-alive` | — | Keeps the player and its store alive when the element leaves the DOM. Call `destroy()` when you're done with it. |

`content-title` and `poster` come from the <DocsLink slug="reference/api/feature-metadata" anchor="player-inputs">metadata feature</DocsLink>. The element's read-only `store` property returns its player store.

The preset root also exports a `PlayerController` bound to the audio player's store. Use it from any custom element inside `<audio-player>`; see <DocsLink slug="reference/api/player-controller">`PlayerController`</DocsLink>.
</FrameworkCase>

## Feature bundle

`audioFeatures` is the array of <DocsLink slug="guides/features">features</DocsLink> the player is configured with, a subset of the <DocsLink slug="reference/api/preset-video" anchor="feature-bundle">video preset's</DocsLink> `videoFeatures`:

<PresetFeatures preset="audio" />

<FrameworkCase frameworks={["react"]}>
Its type, `AudioFeatures`, is the tuple of those features in order. Import it from the package root:

```tsx
import type { AudioFeatures } from '@videojs/react';
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
Its type, `AudioFeatures`, is the tuple of those features in order. Import it from the package root:

```ts
import type { AudioFeatures } from '@videojs/html';
```
</FrameworkCase>

To add or remove a feature, pass your own array to `createPlayer`. The skins expect the features they render controls for.

<FrameworkCase frameworks={["react"]}>
```tsx
import { createPlayer, remotePlaybackFeature } from '@videojs/react';
import { audioFeatures } from '@videojs/react/audio';

const { Player, usePlayer } = createPlayer({
  features: [...audioFeatures, remotePlaybackFeature],
});
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```ts
import { createPlayer, remotePlaybackFeature } from '@videojs/html';
import { audioFeatures } from '@videojs/html/audio';

const { PlayerElement } = createPlayer({
  features: [...audioFeatures, remotePlaybackFeature],
});

customElements.define('my-audio-player', PlayerElement);
```
</FrameworkCase>

## Skins

- <DocsLink slug="reference/components/audio-skin">AudioSkin</DocsLink> — the default skin, with the modern, frosted look.
- <DocsLink slug="reference/components/audio-neutral-skin">NeutralAudioSkin</DocsLink> — the visually lighter variant, closer to a classic control bar.

## Media

<FrameworkCase frameworks={["react"]}>
The preset exports <DocsLink slug="reference/components/audio">`Audio`</DocsLink>, which renders a native `<audio>`. Swap it for any compatible <DocsLink slug="guides/media-sources">media component</DocsLink>, such as <DocsLink slug="reference/components/hls-audio">`HlsAudio`</DocsLink> for HLS.
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
The preset plays through a native <DocsLink slug="reference/components/audio">`<audio>`</DocsLink>, so it registers no media element of its own. Swap it for any compatible <DocsLink slug="guides/media-sources">media element</DocsLink>, such as <DocsLink slug="reference/components/hls-audio">`<hls-audio>`</DocsLink> for HLS.
</FrameworkCase>

## Exports

<FrameworkCase frameworks={["react"]}>
`@videojs/react/audio` exports:

| Export | Description |
| --- | --- |
| `AudioPlayer`, `AudioPlayerProps` | The preconfigured [player](#player). |
| `usePlayer` | The player-store hook, typed to `audioFeatures`. |
| `audioFeatures` | The [feature bundle](#feature-bundle). |
| `AudioSkin`, `AudioSkinProps` | The default [skin](#skins). |
| `NeutralAudioSkin`, `NeutralAudioSkinProps` | The neutral [skin](#skins). |
| `Audio`, `AudioProps` | The [media](#media) component. |

Stylesheets: `@videojs/react/audio/skin.css` and `@videojs/react/audio/neutral-skin.css`.
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
The preset root, `@videojs/html/audio`, has no side effects. Importing it never registers an element:

| Export | Description |
| --- | --- |
| `AudioPlayerElement` | The [player](#player) element class. |
| `PlayerController` | The player controller, bound to the audio player's store. |
| `audioFeatures` | The [feature bundle](#feature-bundle). |
| `AudioSkinElement` | The default [skin](#skins) element class. |
| `NeutralAudioSkinElement` | The neutral [skin](#skins) element class. |

Registration entry points are side-effect-only:

| Entry point | Registers |
| --- | --- |
| `@videojs/html/audio/player` | `<audio-player>` |
| `@videojs/html/audio/skin` | `<audio-skin>`, `<media-container>`, and the UI elements the skin composes |
| `@videojs/html/audio/neutral-skin` | `<audio-neutral-skin>`, `<media-container>`, and the UI elements the neutral skin composes |
| `@videojs/html/audio/ui` | `<media-container>` and the UI elements of the default skin, without the skin, for a layout you write yourself |
| `@videojs/html/audio/neutral-ui` | `<media-container>` and the UI elements of the neutral skin, without the skin |
</FrameworkCase>
