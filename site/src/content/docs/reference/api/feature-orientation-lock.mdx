Locks screen orientation while fullscreen is active. Set the type to `auto` to choose landscape or portrait from the attached video's dimensions.

## Import

<FeatureImports feature="orientationLock" />

<FeatureReference feature="orientationLock" />

### Usage

Selecting the feature adds it to the player.

<FrameworkCase frameworks={["react"]}>
```tsx title="player.tsx"
import { Container, createPlayer, features } from '@videojs/react';
import { videoFeatures } from '@videojs/react/video';

export const { Player } = createPlayer({
  features: [...videoFeatures, features.orientationLock],
});
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```ts title="player.ts"
import { createPlayer, features } from '@videojs/html';
import { videoFeatures } from '@videojs/html/video';

const { PlayerElement: MyPlayer } = createPlayer({
  features: [...videoFeatures, features.orientationLock],
});

customElements.define('my-player', MyPlayer);
```
</FrameworkCase>

### Orientation type

The feature locks to `landscape` unless the provider sets another orientation type. The value can change while the player is running; if the screen is already locked, it re-locks to the new type. `auto` selects `landscape` when `videoWidth` is greater than `videoHeight`, and `portrait` when `videoHeight` is greater. It waits for nonzero video dimensions and follows dimension changes while fullscreen is active. Equal dimensions, including square video, do not request an orientation lock.

<FrameworkCase frameworks={["react"]}>
```tsx
<Player orientationLockType="auto">
  <Container>
    <Video src="/video.mp4" />
  </Container>
</Player>
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```html
<my-player orientation-lock-type="auto">
  <video src="/video.mp4"></video>
</my-player>
```

The attribute only exists on a player that selected the feature. Setting it on
an element built from `videoFeatures` alone does nothing.
</FrameworkCase>

Use an explicit Screen Orientation API value such as `portrait` when the orientation should not depend on video dimensions. Clearing the value restores `landscape`.

### Selector

<FrameworkCase frameworks={["react"]}>
Pass `selectOrientationLock` to <DocsLink slug="reference/api/use-player">`usePlayer`</DocsLink> to subscribe to the lock state. Returns `undefined` if the orientation lock feature is not configured.
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
Pass `selectOrientationLock` to <DocsLink slug="reference/api/player-controller">`PlayerController`</DocsLink> to subscribe to the lock state. Returns `undefined` if the orientation lock feature is not configured.
</FrameworkCase>

<FrameworkCase frameworks={["react"]}>
```tsx title="OrientationToggle.tsx"
import { selectOrientationLock, usePlayer } from '@videojs/react';

function OrientationToggle() {
  const lock = usePlayer(selectOrientationLock);
  if (!lock) return null;

  return (
    <button onClick={() => lock.setOrientationLockType('portrait')}>
      Lock portrait
    </button>
  );
}
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```ts title="orientation-toggle.ts"
import { createPlayer, features, UIElement, selectOrientationLock } from '@videojs/html';
import { videoFeatures } from '@videojs/html/video';

const { PlayerController } = createPlayer({
  features: [...videoFeatures, features.orientationLock],
});

class OrientationToggle extends UIElement {
  readonly #lock = new PlayerController(this, selectOrientationLock);
}
```
</FrameworkCase>

Unsupported browsers and rejected lock requests leave the device orientation unchanged. A warning is logged in development builds only.
