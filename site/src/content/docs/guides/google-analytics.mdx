Send video starts, progress milestones, completions, and playback interactions to Google Analytics 4 (GA4). Add the Google Analytics <DocsLink slug="guides/architecture">extension</DocsLink> to a player and it reports on whichever media that player is playing.

## Installation

This guide assumes your page already loads GA4 through Google Tag (`gtag.js`) or Google Tag Manager (GTM). The extension sends events to them; it doesn't load either one.

<FrameworkCase frameworks={["react"]}>
```bash
pnpm add @videojs/react @videojs/google-analytics
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```bash
pnpm add @videojs/html @videojs/google-analytics
```
</FrameworkCase>

## Recommended approach

Put the extension inside the player next to the media, and give it the title you want to see in your reports. It renders nothing, so its position doesn't matter:

<FrameworkCase frameworks={["react"]}>
```tsx title="App.tsx"
import { Container, createPlayer } from '@videojs/react';
import { GoogleAnalytics } from '@videojs/react/extensions/google-analytics';
import { Video } from '@videojs/react/media/video';
import { videoFeatures } from '@videojs/react/video';

const { Player } = createPlayer({ features: videoFeatures });

export default function App() {
  return (
    <Player>
      <Container>
        <Video src="https://example.com/video.mp4" />
        <GoogleAnalytics metadata={{ video_title: 'Keynote Presentation' }} /> {/* [!code focus] */}
      </Container>
    </Player>
  );
}
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```html title="index.html"
<video-player>
  <media-container>
    <video src="https://example.com/video.mp4"></video>
    <google-analytics metadata-video-title="Keynote Presentation"></google-analytics> <!-- [!code focus] -->
  </media-container>
</video-player>
<script type="module">
  import '@videojs/html/video/player';
  import '@videojs/html/ui/container';
  import '@videojs/html/extensions/google-analytics';
</script>
```
</FrameworkCase>

That's the whole setup. Without a title, the extension falls back to the title the media reports (Mux and Vimeo media report one, for example), then to the source URL. It never reads a `title` attribute on `<video>`, so set the title on the extension.

## How it works

The extension listens to the media the player is using and turns playback into GA4's [Enhanced Measurement](https://support.google.com/analytics/answer/9216061) video events (`video_start`, `video_progress`, `video_complete`) plus interaction events such as `pause`, `seek`, and `fullscreenEnter`. Each event goes to `window.dataLayer`, which GTM reads, and to `window.gtag` when it exists.

Every event carries the current time, duration, playback position as a percentage, stream type, title, and URL, followed by anything else you put in `metadata`. The <DocsLink slug="reference/components/google-analytics" anchor="events">GoogleAnalytics reference</DocsLink> lists each event, when it fires, and every parameter.

## Availability and constraints

- Google Analytics tracking is opt-in. No media component sends events until you add the extension.
- GA4 must already be on the page through `gtag.js` or GTM. Without it, events collect in `window.dataLayer` and go nowhere.
- Progress milestones (10%, 25%, 50%, and 75%) need a known duration, so live streams don't send `video_progress`.
- GA4 caps the parameters per event, which limits how many custom dimensions you can add. See the <DocsLink slug="reference/components/google-analytics" anchor="collection-limits">collection limits</DocsLink>.
- Custom dimensions appear in GA4 reports only after you [register them](https://support.google.com/analytics/answer/14240153) in GA4.

## Common variations

### Add custom dimensions

Put any extra keys in `metadata`. Each one is sent as an event parameter with every event:

<FrameworkCase frameworks={["react"]}>
```tsx
<GoogleAnalytics
  metadata={{
    video_title: 'Keynote Presentation',
    video_series: 'Annual Conference',
    video_id: 'conf_2026_01',
  }}
/>
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```html
<google-analytics
  metadata-video-title="Keynote Presentation"
  metadata-video-series="Annual Conference"
  metadata-video-id="conf_2026_01"
></google-analytics>
```

To pass an object instead, assign the `metadata` property. It overrides attributes with the same key.
</FrameworkCase>

Naming dimensions after their [Mux Data](https://www.mux.com/docs/guides/make-your-data-actionable-with-metadata) equivalents, such as `video_series` and `video_id`, keeps the two reports comparable if you also <DocsLink slug="guides/mux-data">monitor playback with Mux Data</DocsLink>.

### Use a renamed data layer

If your GTM snippet renames the data layer, pass the same name:

<FrameworkCase frameworks={["react"]}>
```tsx
<GoogleAnalytics dataLayerName="myDataLayer" />
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```html
<google-analytics data-layer-name="myDataLayer"></google-analytics>
```
</FrameworkCase>

### Send events to another tool as well

Pass an `onEvent` callback. It receives each event's name and parameters before they're sent to GA4:

<FrameworkCase frameworks={["react"]}>
```tsx
<GoogleAnalytics onEvent={(event, params) => myAnalytics.track(event, params)} />
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```ts
const ga = document.querySelector('google-analytics');
ga.onEvent = (event, params) => myAnalytics.track(event, params);
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
### Load from a CDN

When you load Video.js from a CDN, add the extension's script after the player's:

```html title="index.html"
<script type="module" src="https://cdn.jsdelivr.net/npm/@videojs/cdn/video.js"></script>
<script type="module" src="https://cdn.jsdelivr.net/npm/@videojs/cdn/extensions/google-analytics.js"></script>

<video-player>
  <media-container>
    <video src="https://example.com/video.mp4"></video>
    <google-analytics metadata-video-title="Keynote Presentation"></google-analytics>
  </media-container>
</video-player>
```
</FrameworkCase>

## Troubleshooting

### No video events reach GA4

Check that `gtag.js` or GTM loads on the page. Then turn on `debug` to log each event the extension sends:

<FrameworkCase frameworks={["react"]}>
```tsx
<GoogleAnalytics debug />
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```html
<google-analytics debug></google-analytics>
```
</FrameworkCase>

```
[GoogleAnalyticsExtension] Event: "video_start" {video_current_time: 0, video_duration: 120, ...}
```

If events log but don't reach GA4 through GTM, add a GA4 event tag with a custom event trigger for them. GTM doesn't forward data layer events on its own.

### No `video_progress` events

The stream is live, its duration is unknown, or `disableProgress` is set. Check `video_stream_type` and `video_duration` in the `debug` output.

### Live streams report as on-demand

The extension asks the media whether it's live, and some media can't tell. Set the stream type yourself:

<FrameworkCase frameworks={["react"]}>
```tsx
<GoogleAnalytics metadata={{ video_title: 'Live Keynote', video_stream_type: 'live' }} />
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```html
<google-analytics metadata-video-title="Live Keynote" metadata-video-stream-type="live"></google-analytics>
```
</FrameworkCase>

### Reports show URLs instead of titles

Set `video_title` in `metadata`. The URL is the fallback when neither you nor the media provides a title.
