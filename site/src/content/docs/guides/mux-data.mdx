[Mux Data](https://www.mux.com/data) measures playback quality: startup time, rebuffering, playback failures, and watch time. Add the Mux Data <DocsLink slug="guides/architecture">extension</DocsLink> to a player and it monitors whichever media that player is playing:

<FrameworkCase frameworks={["react"]}>
Install the extension alongside the framework façade. The MuxVideo example also installs the Mux playback adapter:
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
Install the extension alongside the framework façade. The `<mux-video>` example also installs the Mux playback adapter:
</FrameworkCase>

<FrameworkCase frameworks={["react"]}>
```bash
pnpm add @videojs/react @videojs/mux-video @videojs/mux-data
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```bash
pnpm add @videojs/html @videojs/mux-video @videojs/mux-data
```
</FrameworkCase>

<FrameworkCase frameworks={["react"]}>
```tsx title="App.tsx"
import { Container, createPlayer } from '@videojs/react';
import { MuxData } from '@videojs/react/extensions/mux-data';
import { MuxVideo } from '@videojs/react/media/mux-video';
import { videoFeatures } from '@videojs/react/video';

const { Player } = createPlayer({ features: videoFeatures });

export default function App() {
  return (
    <Player>
      <Container>
        <MuxVideo source={{ playbackId: 'BV3YZtogl89mg9VcNBhhnHm02Y34zI1nlMuMQfAbl3dM' }} playsInline />
        <MuxData /> {/* [!code focus] */}
      </Container>
    </Player>
  );
}
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```html title="index.html"
<video-player>
  <media-container>
    <mux-video src="https://stream.mux.com/BV3YZtogl89mg9VcNBhhnHm02Y34zI1nlMuMQfAbl3dM.m3u8" playsinline></mux-video>
    <mux-data></mux-data> <!-- [!code focus] -->
  </media-container>
</video-player>
<script type="module">
  import '@videojs/html/video/player';
  import '@videojs/html/ui/container';
  import '@videojs/html/media/mux-video';
  import '@videojs/html/extensions/mux-data';
</script>
```
</FrameworkCase>

That's the whole setup for Mux-hosted playback — no environment key required. The extension renders nothing; place it inside the player, as a sibling of the media element.

<Aside type="note">
Mux Data is opt-in. No media element monitors playback on its own, Mux ones included, so nothing is measured and no beacons are sent until you add the extension.
</Aside>

## Set the environment key

Mux Data needs to know which environment a view belongs to. For Mux-hosted playback, you do not need to set an environment key. The extension reports the Mux playback ID as the view's `video_id`, and Mux attributes the view to the environment that owns that playback ID.

Set `envKey` when you monitor a source Mux doesn't host, like a self-hosted HLS or DASH stream. Find the key in the [Mux dashboard](https://dashboard.mux.com/settings/data):

<FrameworkCase frameworks={["react"]}>
For the hls.js example, also install `@videojs/hlsjs-video`. Replace the media and extension in the primary example with `<MonitoredHlsVideo />`:

```bash
pnpm add @videojs/hlsjs-video
```

```tsx
import { HlsJsVideo } from '@videojs/react/media/hlsjs-video';
import { MuxData } from '@videojs/react/extensions/mux-data';

function MonitoredHlsVideo() {
  return (
    <>
      <HlsJsVideo src="https://example.com/stream.m3u8" />
      <MuxData envKey="YOUR_ENV_KEY" /> {/* [!code focus] */}
    </>
  );
}
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
For the hls.js example, also install `@videojs/hlsjs-video`. Replace `<mux-video>` in the primary example with `<hlsjs-video>` and keep `<hlsjs-video>` and `<mux-data>` inside the container:

```bash
pnpm add @videojs/hlsjs-video
```

```html
<hlsjs-video src="https://example.com/stream.m3u8"></hlsjs-video>
<mux-data env-key="YOUR_ENV_KEY"></mux-data> <!-- [!code focus] -->
<script type="module">
  import '@videojs/html/media/hlsjs-video';
  import '@videojs/html/extensions/mux-data';
</script>
```
</FrameworkCase>

An explicit `envKey` overrides the environment Mux infers from the playback ID. Set one to send Mux-hosted views to a specific environment.

## How it works

<FrameworkCase frameworks={["react"]}>
The extension attaches to the media the player is using, not to a specific element type, so it monitors <DocsLink slug="reference/components/mux-video">MuxVideo</DocsLink>, <DocsLink slug="reference/components/hlsjs-video">HlsJsVideo</DocsLink>, <DocsLink slug="reference/components/dash-video">DashVideo</DocsLink>, and the rest alike.
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
The extension attaches to the media the player is using, not to a specific element type, so it monitors <DocsLink slug="reference/components/mux-video">`<mux-video>`</DocsLink>, <DocsLink slug="reference/components/hlsjs-video">`<hlsjs-video>`</DocsLink>, <DocsLink slug="reference/components/dash-video">`<dash-video>`</DocsLink>, and the rest alike.
</FrameworkCase>

How much the extension reports depends on the engine playing the stream. All media report the playback metrics available from the media element. The extension also recognizes [hls.js](https://github.com/video-dev/hls.js/) and [dash.js](https://github.com/Dash-Industry-Forum/dash.js) engines and hands them to the Mux Data SDK, which adds stream-level detail: rendition switches, segment request timing and throughput, and engine errors. Media without a JavaScript engine, like native HLS or a plain `<video>`, report only the element-level metrics.

The `video_id` it reports is the Mux playback ID for streams served from `stream.mux.com`, and the source URL otherwise. Each view also gets a generated `view_session_id`. Override either through `metadata`.

## Describe the view

Pass Mux Data [metadata](https://www.mux.com/docs/guides/make-your-data-actionable-with-metadata) to label views with your own titles, viewer IDs, and custom dimensions. `metadata` takes an object. In HTML, set it as a JavaScript property:

<FrameworkCase frameworks={["react"]}>
```tsx
<MuxData metadata={{ video_title: 'Big Buck Bunny', viewer_user_id: 'u_789' }} />
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```ts
const muxData = document.querySelector('mux-data');
muxData.metadata = { video_title: 'Big Buck Bunny', viewer_user_id: 'u_789' }; // [!code focus]
```
</FrameworkCase>
