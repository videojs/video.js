Add a decorative video behind your page content. Start with an MP4 or WebM file, which browsers can play directly. If your video is delivered as HLS, use the HLS or Mux option below.

</FrameworkCase>

## How it works

<FrameworkCase frameworks={["react"]}>
BackgroundVideo renders a native `<video>` with muted, looping, inline playback. The example disables its default autoplay with `autoPlay={false}` and starts playback after checking the motion preference. The decorative wrapper contains the video and an empty-alt poster; it is hidden from assistive technology and ignores pointer input.
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
`<background-video>` renders a native `<video>` with muted, looping, inline playback. The example disables its default autoplay with `noautoplay` and starts playback after checking the motion preference. Its `target` property exposes the native video for `play()` and `pause()`. The decorative wrapper contains the video and an empty-alt poster; it is hidden from assistive technology and ignores pointer input.
</FrameworkCase>

The page defines the hero's size. The video fills that space with `--media-object-fit: cover`, while the poster stays behind it. The motion button pauses and hides the video, revealing the poster. It sits outside the decorative wrapper so keyboard and screen-reader users can operate it.

When `prefers-reduced-motion` is active, the script pauses playback and the CSS hides the video and motion button. CSS hiding alone does not stop playback. If the browser rejects `play()`, the example keeps the poster visible.

Set size, position, and transforms on the decorative wrapper so the poster and video stay together.

## Availability and constraints

<FrameworkCase frameworks={["react"]}>
- Use a source the browser can play directly, such as MP4 or WebM.
- Safari can play HLS URLs directly. Other browsers cannot do so reliably, so use an HLS variation below when the same `.m3u8` URL must work across browsers.
- BackgroundVideo does not create a poster or report analytics. Keep the poster in your page and add analytics only when you need them.
- Provide a way to pause or hide persistent background motion. The example includes that control and follows `prefers-reduced-motion`. For the streaming variations below, stop and restart motion by mounting and unmounting the video.
- If the video communicates information, remove `aria-hidden`, give it an accessible name and controls, and use a regular video player.
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
- Use a source the browser can play directly, such as MP4 or WebM.
- Safari can play HLS URLs directly. Other browsers cannot do so reliably, so use an HLS variation below when the same `.m3u8` URL must work across browsers.
- `<background-video>` does not create a poster or report analytics. Keep the poster in your page and add analytics only when you need them.
- Provide a way to pause or hide persistent background motion. The example includes that control and follows `prefers-reduced-motion`. For the streaming variations below, stop and restart motion by adding and removing the element.
- If the video communicates information, remove `aria-hidden`, give it an accessible name and controls, and use a regular video player.
</FrameworkCase>

## Common variations

Choose a variation based on the source you already have:

<FrameworkCase frameworks={["react"]}>
| Need | Use |
| --- | --- |
| Cross-browser HLS with a small background-only player | <DocsLink slug="reference/components/hls-background-video">HlsBackgroundVideo</DocsLink> |
| The same background-only player for a Mux HLS URL | <DocsLink slug="reference/components/mux-background-video">MuxBackgroundVideo</DocsLink> |
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
| Need | Use |
| --- | --- |
| Cross-browser HLS with a small background-only player | <DocsLink slug="reference/components/hls-background-video">`<hls-background-video>`</DocsLink> |
| The same background-only player for a Mux HLS URL | <DocsLink slug="reference/components/mux-background-video">`<mux-background-video>`</DocsLink> |
</FrameworkCase>

These streaming background components always autoplay. They ignore `autoPlay={false}` and `noautoplay`.

<FrameworkCase frameworks={["react"]}>
Keep the poster and motion button from the primary example. Render the streaming component only while `motionEnabled` is true, and remove the native video's `play()`/`pause()` effect. Unmounting the component stops playback; mounting it again restarts the stream.
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
Keep the poster and motion button from the primary example. Change `setMotion` to create and append a streaming element only when motion is enabled, and remove it when motion is disabled. Do not set `keep-alive`: removal must destroy playback. Create a new element each time motion is enabled; do not reuse the removed one. These elements expose the inner video as `video`, rather than the native background element's `target`.
</FrameworkCase>

### Play an HLS video

<FrameworkCase frameworks={["react"]}>
HlsBackgroundVideo plays an HLS video without adding controls, audio, or captions. Pass a complete HLS URL through `src`:
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
`<hls-background-video>` plays an HLS video without adding controls, audio, or captions. Pass a complete HLS URL through `src`:
</FrameworkCase>

<FrameworkCase frameworks={["react"]}>
```bash
pnpm add @videojs/react @videojs/spf
```

```tsx
import { HlsBackgroundVideo } from '@videojs/react/media/hls-background-video';

<HlsBackgroundVideo
  className="hero-media"
  src="https://media.example.com/hero.m3u8"
  crossOrigin="anonymous"
  onError={() => console.error('The background stream could not play')}
/>
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```bash
pnpm add @videojs/html @videojs/spf
```

```html
<script type="module">
  import '@videojs/html/media/hls-background-video';
</script>

<hls-background-video
  class="hero-media"
  src="https://media.example.com/hero.m3u8"
  crossorigin
></hls-background-video>
```
</FrameworkCase>

Your HLS stream must be unencrypted and use fragmented MP4 video segments, also called fMP4 or CMAF. The component chooses one video size when playback starts and does not switch sizes later. It cannot play older MPEG-TS segments.

### Play a Mux HLS URL

<FrameworkCase frameworks={["react"]}>
MuxBackgroundVideo is a Mux-named alias for HlsBackgroundVideo. Pass a complete Mux HLS URL, not a bare playback ID or `source` object:

It uses the same `@videojs/spf` installation shown for HlsBackgroundVideo above.
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
`<mux-background-video>` is a Mux-named alias for `<hls-background-video>`. Pass a complete Mux HLS URL, not a bare playback ID or `source` object:

It uses the same `@videojs/spf` installation shown for `<hls-background-video>` above.
</FrameworkCase>

<FrameworkCase frameworks={["react"]}>
```tsx
import { MuxBackgroundVideo } from '@videojs/react/media/mux-background-video';

<MuxBackgroundVideo
  className="hero-media"
  src="https://stream.mux.com/PLAYBACK_ID.m3u8?max_resolution=720p"
  crossOrigin="anonymous"
/>
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```html
<script type="module">
  import '@videojs/html/media/mux-background-video';
</script>

<mux-background-video
  class="hero-media"
  src="https://stream.mux.com/PLAYBACK_ID.m3u8?max_resolution=720p"
  crossorigin
></mux-background-video>
```
</FrameworkCase>

This component does not create a Mux poster, preview thumbnails, or analytics session. Keep the poster in your page and add analytics separately when you need them.

## Troubleshooting

### An HLS URL works in Safari but not another browser

<FrameworkCase frameworks={["react"]}>
BackgroundVideo hands its `src` to the browser's `<video>` element. Use HlsBackgroundVideo for a supported fMP4 HLS source, or MuxBackgroundVideo for a Mux HLS URL.
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
`<background-video>` hands its `src` to the browser's `<video>` element. Use `<hls-background-video>` for a supported fMP4 HLS source, or `<mux-background-video>` for a Mux HLS URL.
</FrameworkCase>

### The video does not fill or follow transforms

Set the size, transforms, and measurements on the wrapper that contains the video and poster. Size the background-video component to fill that wrapper.

### No poster or Mux analytics appear

The background-video components do not provide them. Render an empty-alt poster in the same wrapper as the video, and add analytics separately.
