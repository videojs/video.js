Video.js v10 is a complete rebuild from the ground up, designed to be more modular, framework-flexible, and aligned with modern web development practices.

## Current versions

### Version 10

- Stable and recommended for new projects. Start with the <DocsLink slug="guides/installation">installation guide</DocsLink>
- Follows semantic versioning: breaking changes wait for a new major version
- Covers the fundamentals of Video.js 8
- Migration guides for <DocsLink slug="guides/migrate-from-video-js-8">Video.js 8</DocsLink>, <DocsLink slug="guides/migrate-from-mux-player">Mux Player</DocsLink>, <DocsLink slug="guides/migrate-from-plyr">Plyr</DocsLink>, <DocsLink slug="guides/migrate-from-media-chrome">Media Chrome</DocsLink>, and <DocsLink slug="guides/migrate-from-vidstack">Vidstack</DocsLink>, each listing its known gaps

### Version 8

- Maintained with bug fixes and critical security patches only
- No new features will be planned
- Community contributions still welcome
- Documentation available at [legacy.videojs.org](https://legacy.videojs.org)

### Version 9

- Reserved only for urgent API-breaking changes that cannot be avoided

## After 10.0

These land in 10.x minor releases as they're ready.

### Feature parity with Video.js 8 contrib

- Ads integration
- Analytics support
- Plugin ecosystem migration, dependent on community contributions

### Engine development focus

- Lightweight adaptive streaming
- MoQ (Media over QUIC) support

## Support plan for Video.js 8

- Documentation stays at [legacy.videojs.org](https://legacy.videojs.org)
- Hosted CDN copies remain available
- From 2027, security patches only, and community contributions are de-prioritized
