## Add your player

<Steps>
  <Step number={1} title="Add the player component">
    Add a component that imports the elements it renders. Svelte passes hyphenated tags through to the browser, so no compiler configuration is needed. The imports register the selected player, skin, media, and extensions; the markup composes them.

    <SvelteCreateCodeBlock client:visible={{ rootMargin: "200px" }} />
  </Step>
  <Step number={2} title="Render the player">
    Render the component in a page and pass it the media source you selected above.

  </Step>

## Run your app

Start the app and verify that the selected media plays.

<ProjectCommands client:visible={{ rootMargin: "200px" }} part="run" serverFramework="svelte" serverTemplate="vite" />

That's it! You now have a working Video.js player.

<Aside type="note" title="Server rendering with SvelteKit">
Keep the element imports static. SvelteKit renders the custom-element markup on the server, and the browser upgrades it when the page loads. Put code that needs the element or browser APIs in `onMount`. See <DocsLink slug="guides/svelte" anchor="use-sveltekit">Use SvelteKit</DocsLink> for the details.
</Aside>
