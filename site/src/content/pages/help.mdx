## Video not playing?

If a video on another site won't play, try these first:

- Reload the page.
- Update your browser, or try a different one.
- Check your internet connection.
- Turn off ad or content blockers for that site. They sometimes block the video along with the ads.

Still stuck? Contact the site that's showing the video. We make the player, but we don't host their videos and can't see their servers.

If you run a site that uses Video.js, our [support options](/support) cover community help and enterprise support.

## What is Video.js?

Video.js is a free, open-source video player for websites. It's been around since 2010 and runs on millions of sites. The current version ships as web components for HTML and as components for React.

It's built at Mux by the people behind Video.js, Plyr, Vidstack, and Media Chrome, with contributions from engineers who work on other players.

The browser's `<video>` tag can play a file, but that's about it. It doesn't stream adaptively outside Safari, its controls can't be restyled, and it has no menus for captions, quality, or speed. Video.js adds those pieces as separate components, so you only ship what you use. [HTML5 video support](/html5-video-support) covers the gaps in more detail, and <DocsLink slug="guides/why-videojs">Why Video.js?</DocsLink> explains how we approach them.

## Build one yourself

A basic player looks like this:

```html title="index.html"
<script type="module" src="{{VJS10_CDN_BASE}}/video.js"></script>

<video-player>
  <video-skin>
    <video src="/video.mp4" playsinline></video>
  </video-skin>
</video-player>
```

```tsx title="MyPlayer.tsx"
import '@videojs/react/video/skin.css';
import { Video, VideoPlayer, VideoSkin } from '@videojs/react/video';

export function MyPlayer({ src }: { src: string }) {
  return (
    <VideoPlayer>
      <VideoSkin>
        <Video src={src} playsInline />
      </VideoSkin>
    </VideoPlayer>
  );
}
```
